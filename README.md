# Sevenail Next.js site

A Next.js App Router project retaining the original multi-page Sevenail site.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. Existing `.html` links are routed to their Next.js pages.

## Build

```bash
npm run build
npm start
```

Site assets are served from `public/`; source page markup remains in the repository root and is rendered by the App Router.
