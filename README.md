# Sevenail Next.js site

Next.js App Router project for the Sevenail website. Legacy page markup is stored in `content/pages`, routes live in `app`, and public assets are grouped under `public/assets`.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. Existing `.html` links are routed to their Next.js pages.

## Build

```bash
npm run build
npm start
```
